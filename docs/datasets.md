# Dataset Strategy

Recommended public benchmarks include BDD100K for diverse road scenes, KITTI for detection/depth-compatible experiments, Cityscapes for urban semantics, MOT-style data for tracking, and GTSRB/GTSDB-compatible data for traffic signs. Dataset licenses and annotations must be checked before redistribution.

Keep raw datasets outside git. Store only configuration, split manifests and checksums needed for reproducibility.
